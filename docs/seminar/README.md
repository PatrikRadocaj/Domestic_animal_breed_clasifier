# Seminar and presentation archive

These files preserve the seminar, presentation versions, figures, exam notes and authoring scripts from the original desktop workspace. Earlier document versions are historical drafts and may contain superseded results. Retained filenames do not imply that the contents were scientifically revalidated during this archival commit.

The JavaScript generators use `docx` and `pptxgenjs`; run `npm ci` in this directory to restore dependencies. Some historical generators contain absolute paths to the original desktop workspace and must be adapted before rebuilding elsewhere.

Raw datasets, model checkpoints, full training outputs and submission ZIP archives remain local and are intentionally excluded from Git.
